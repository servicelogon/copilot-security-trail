# Copilot Security Trail

Plain HTML, CSS, and vanilla JS. No build step.

Open `index.html` in a browser, or from this folder:

```
python3 -m http.server 8080
```

Dark Copilot chrome on a flat terrain map. Progress is saved in `localStorage` under `copilot-security-trail.v1`. Dates use America/New_York.

Same five stations and Microsoft Learn copy. Fluent 2 surfaces (Segoe UI, 4px buttons, 24px card padding) and Fluent System outline icons (Sparkle, Shield, Map, Checkmark).
